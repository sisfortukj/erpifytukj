Folder ini menampung file PDF sertifikat.

Cara pakai (tanpa backend):
1. Beri nama file sesuai kode sertifikat, contoh:
   sertifikat/SAP-2026-0001.pdf
2. Upload ke folder ini lewat File Manager Hostinger.
3. Tombol "Lihat Sertifikat (PDF)" di halaman sertifikat.html akan
   muncul otomatis saat kode sertifikat dicari (file dicek keberadaannya).

Cara pakai (dengan backend PHP aktif):
1. Buka panel admin > Sertifikasi > Tambah/Edit data.
2. Gunakan tombol unggah PDF pada kolom "File PDF Sertifikat",
   file akan tersimpan ke folder uploads/sertifikat/ secara otomatis.
